# FuFu Bakery

FuFu Bakery is the library's cute line-drawing bakery case: irregular black pen lines, generous paper-white space, and small butter-yellow and powder-blue crayon accents.

The welcome screen enters the bakery home. Four paper-like action tiles open the menu or member space, the bottom navigation changes screens, and menu/perk actions provide immediate local feedback. `?embed=1` produces the stable `390 x 844` library preview; `?embed=1&view=home`, `menu`, or `member` opens a specific screen.

`assets/fufu-line-effect-board.png` is the reviewed three-screen effect image used as the source for UI decomposition. `assets/fufu-baker.png` and `assets/fufu-friends-lineup.png` are the generated illustration assets. Text, controls, status bar, icon sprite, stamps, cards, and navigation are code-rendered. `mobile-preview.png` is the library poster and `fufu-bakery-demo.mp4` records the primary interaction path.
