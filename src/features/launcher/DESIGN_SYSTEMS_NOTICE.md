# Design system preset source

The design-system preset browser in `launcher.html` references DESIGN.md documents from:

- Project: `VoltAgent/awesome-design-md`
- Website: https://getdesign.md/
- Repository: https://github.com/VoltAgent/awesome-design-md
- License: MIT

The upstream DESIGN.md documents describe design tokens and patterns analyzed from publicly visible websites. ONDesign does not bundle proprietary brand font files or claim ownership of the referenced brands' visual identities. Brand-specific font family names may be shown as design references; the live preview falls back to system fonts when those fonts are unavailable.
