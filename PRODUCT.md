# Product

## Register

product

## Users

UI designers, frontend engineers, and product builders who need to compare established design systems against the same product task. They use the laboratory while choosing implementation conventions, checking component mappings, and preparing code or token exports.

## Product Purpose

The Design System Lab keeps page content stable while users switch page templates, design systems, brand themes, devices, and appearance. Success means a user can immediately see how Apple HIG, Material 3, and Ant Design change a working page, understand the component mapping, and export a useful implementation starting point without confusing a design system with a brand theme.

## Brand Personality

Professional, restrained, and tool-like. The interface should feel precise enough for experienced practitioners, understandable without onboarding copy, and quiet enough that the rendered design-system differences remain the focus.

## Anti-references

- A marketing landing page that delays the working tool behind an oversized hero.
- A decorative card wall that turns every option into a floating panel.
- A style filter where unrelated dimensions combine into empty results.
- A flattened mockup that looks convincing but cannot be interacted with.
- A system preview that implies unofficial web renderers are endorsed native implementations.

## Design Principles

- Start with a usable page template, never an empty result.
- Keep page blueprint, design system, brand theme, and device as independent dimensions.
- Change one dimension without mutating the others.
- Show implementation provenance and limitations next to the preview.
- Make comparison and export part of the same workflow, not separate documentation tasks.

## Accessibility & Inclusion

Meet WCAG 2.1 AA contrast and full keyboard-navigation expectations. Controls expose visible focus, clear selected and disabled states, responsive layouts without overlap, semantic status feedback, and reduced-motion behavior. State is never communicated through color alone.
