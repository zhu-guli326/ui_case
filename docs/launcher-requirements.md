# Launcher / Start Designing 页面需求

## 页面目标
帮助用户先确定设计方向与设计系统，再对少量基础界面变量进行微调，并实时预览最终效果，最后保存或复制可复用的 Design DNA。

## 核心功能
- 选择视觉方向，并联动真实案例预览。
- 选择设计系统，继承其颜色、字体、圆角、间距等基础视觉规则。
- 允许用户继续微调字体、圆角、间距与界面密度。
- 右侧实时预览页面与组件状态。
- 保存 Design DNA，并生成可复制提示词。

## 信息结构
1. 视觉方向：方向案例 + 界面密度。
2. 基础规范：设计系统 + 字体 + 圆角 + 间距。
3. 保存并复用：名称、规范摘要、生成提示词、保存与复制。
4. 实时预览：页面/组件切换 + 桌面/移动预览。

## 交互规则
- 设计系统负责提供基础颜色体系，不再额外提供独立颜色选择器，避免同一层级重复配置。
- 设计系统下拉默认优先展示更知名、对 UI Coding 更有参考价值的品牌/产品；其余条目继续保留，并可通过搜索找到。
- 优先顺序采用固定推荐序列，不按字母排序，避免每次打开时顺序变化。
- 字体、圆角、间距保留为可手动微调项。
- 选择设计系统后，预览应同步更新；后续微调只覆盖对应变量。
- 中英文切换必须完整同步，不出现中英混杂。

## 保留项
- 设计系统选择器。
- 全部现有设计系统数据与搜索能力。
- 字体、圆角、间距。
- 视觉方向与密度。
- 实时预览、保存与复制提示词。

## 删除项
- 基础规范中的独立「颜色」选择模块（鼠尾草绿 / 墨黑灰 / 深海蓝 / 暖珊瑚）。
