# Image2 UI Reference Library

This context describes the reference material that can be combined to generate a clickable UI demo while keeping provenance and intent explicit.

## Language

**Component Reference**:
A sourced record of one reusable UI component from a named brand or public design system, including its anatomy, states, behavior, and usage constraints.
_Avoid_: Brand component, component style, component template

**Brand Profile**:
The identity and public design-system context that groups Component References belonging to the same organization or system, such as Google Material Design 3 or Apple Human Interface Guidelines.
_Avoid_: Style profile, visual mood, theme

**Style Profile**:
A reusable visual direction that is not a real brand or official design system, such as editorial commerce, minimal technology, or soft lifestyle.
_Avoid_: Brand, brand profile, official guideline

**Case**:
A screen, layout, or interaction example used as structural and experiential reference.
_Avoid_: Brand template, component library

**Source Status**:
The provenance classification that distinguishes brand-provided material, public guidelines, style references, and custom input. A public-guideline record does not imply affiliation with or endorsement by its owner.
_Avoid_: Official status, certification
