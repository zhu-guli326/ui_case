DEFINE

02 · CREATE
CREATE

BUILD

ITERATE

DESIGN DNA

不是多做几张图，而是先把规则定清楚。

字体、颜色、间距和组件状态都明确以后，AI 才有可能持续做出同一种设计语言。

01
Typography

标题、正文、字重、行高先统一。

02
Color

主色、表面、状态色都有固定角色。

03
Spacing

间距不靠感觉，统一到同一套 scale。

04
Components

Default、Hover、Active、Disabled 都要有规则。
